Project: PhD Academic RAG
Task ID: RAG-005
Goal: Implement selective OCR fallback for PDF pages that have no usable extracted text or are classified as possibly scanned.
The OCR layer must be conservative, page-level, provenance-preserving, and strictly fallback-only.
Do not OCR pages that already have good native PDF text.
Environment
- Python 3.12
- FastAPI
- Pydantic v2
- PyMuPDF
- Existing RAG-001 to RAG-004 architecture must remain intact.
- Project root: F:\phd-rag
Inspect the repository before changing anything.
1. Purpose
RAG-004 found:
478 PDFs
11,490 pages
166 possibly scanned pages
19 affected PDFs

Most of the corpus already has good extractable text.
OCR must therefore be a selective fallback, not the primary extraction method.
The intended flow is:
PDF page
   ↓
native PyMuPDF extraction
   ↓
usable text?
   ├─ YES → keep native text
   └─ NO / POSSIBLY_SCANNED
              ↓
             OCR
              ↓
      preserve OCR provenance

2. OCR engine
Prefer a local OCR solution that works offline on Windows.
Use:
Tesseract OCR

through a lightweight Python wrapper such as:
pytesseract

if Tesseract is available locally.
Do not use cloud OCR.
Do not send documents to external services.
Do not add a heavyweight OCR framework unless necessary.
If Tesseract is not installed, stop and report the exact installation requirement instead of silently changing OCR engines.
3. Languages
The corpus is mainly English but may contain Greek.
Design configuration for at least:
eng
ell

Preferred default OCR language setting:
eng

Greek (`ell`) may still be configured explicitly, but it is not the default.
If a configured language is not installed in Tesseract, report that clearly.
Do not download language packs automatically.
4. New OCR provenance
Extend page/block provenance so the system knows how text was obtained.
Add a controlled enum such as:
TextSource

values:
NATIVE_PDF
OCR

Every PDF text block must indicate its source.
Existing native PDF blocks should become:
text_source = NATIVE_PDF

OCR-derived blocks:
text_source = OCR

Do not mix the two without provenance.
5. OCR eligibility
OCR only when the page is currently:
POSSIBLY_SCANNED

or has:
no meaningful extracted text

Do not OCR ordinary TEXT pages.
Add a configurable threshold rather than hard-coding assumptions throughout the code.
For example:
OCR_MIN_NATIVE_CHARS = 50

but reuse the existing RAG-004 classification logic where possible.
6. Rendering
Render only the target PDF page to an image in memory.
Suggested resolution:
300 DPI

or equivalent PyMuPDF matrix scaling.
Do not render the full PDF at once.
Process:
load page
render page
OCR page
release image
continue

Avoid unnecessary temporary image files where practical.
7. OCR result model
Create an explicit model such as:
OcrPageResult
├── page_number
├── text
├── language
├── confidence: float | None
├── source = OCR
└── character_count

Confidence may remain None if reliable aggregate confidence is not available without extra complexity.
Do not invent confidence values.
8. Integration with ParsedPage
A page that is OCRed should preserve:
page_number
native_text
ocr_text
final_text_source

or an equivalent clean representation.
Important:
- never destroy the original native extraction;
- never overwrite native text irreversibly;
- keep both when OCR fallback was attempted.
Suggested additional fields:
native_text: str | None
ocr_text: str | None
text_source: TextSource
ocr_applied: bool

Exact naming may vary if the model already supports an equivalent structure.
9. Final page text
For a page with good native text:
final page text = native text
text_source = NATIVE_PDF

For an OCR fallback page:
final page text = OCR text
text_source = OCR

Do not automatically concatenate weak native text and OCR text, because this can duplicate content.
Preserve both separately for audit purposes if both exist.
10. OCR block creation
OCR output may initially be represented as one page-level ParsedBlock if reliable layout segmentation is not available.
Example:
block_type = PARAGRAPH
page_number = 84
text_source = OCR
source_locator = page:84:ocr:1

This is acceptable for RAG-005.
Do not attempt advanced OCR layout analysis unless it is trivial with the chosen engine.
Page provenance matters more than perfect block segmentation.
11. Preserve native blocks
If OCR is used on a page that contains weak native text, preserve those original native blocks separately for debugging/audit.
Do not delete them from the parsed representation unless there is a clean model-level reason.
The page's effective retrieval text may use OCR, but provenance must show both sources existed.
12. OCR failure
OCR failure on one page must not cause the entire PDF to fail.
Record a structured page-level OCR error.
Suggested fields:
ocr_error: str | None

Continue parsing remaining pages.
This is intentionally different from native PDF parse failure.
