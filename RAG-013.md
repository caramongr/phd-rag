1. Required modes
Implement these user-facing modes:
EVIDENCE
WRITING
CONSISTENCY
SUPERVISOR
RESEARCH

They are orchestration presets only.
2. EVIDENCE mode
Purpose:
answer a research question using scholarly evidence only

Use:
RAG-009 EVIDENCE retrieval
RAG-011 grounded generation
RAG-012 validation + Harvard citations

Do not use my_work, guidance, summaries or supervision as scholarly evidence.
Internet discovery may be shown separately, but metadata-only external results are not evidence.
3. WRITING mode
Purpose:
help draft PhD prose grounded in literature while respecting the user's existing work and writing rules

Use:
literature = evidence
my_work = terminology/continuity only
rules/guidance = writing instructions only

Do not cite my_work or guidance as external evidence.
Apply the user's writing preferences:
plain academic prose
short varied sentences
clarity over sophistication
no em dash
Harvard citations
no invented claims
no promotional language

Output must still pass RAG-012 citation validation.
4. CONSISTENCY mode
Purpose:
compare a question, paragraph or draft against the user's existing thesis/work

Primary sources:
my_work
literature when checking factual consistency
rules when checking style

Typical outputs:
terminology differences
contradictions
duplicated ideas
unsupported claims
places where newer evidence conflicts with old wording

Do not automatically rewrite unless explicitly requested.
5. SUPERVISOR mode
Purpose:
surface what supervision material says about a topic

Use:
supervision
rules
guidance

This mode is not scholarly evidence mode.
Clearly label:
supervisor/guidance context

Do not convert supervisor notes into literature citations.
6. RESEARCH mode
Purpose:
search both the local corpus and external academic sources

Use:
RAG-009 local retrieval
+
RAG-010 external discovery

Keep output separated:
LOCAL EVIDENCE
NEW EXTERNAL PAPERS
ALREADY IN CORPUS
POSSIBLE MATCHES

Do not silently merge external metadata into evidence.
