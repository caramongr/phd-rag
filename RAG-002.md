The scanner must:

- count every file encountered;

- identify unsupported files;
- calculate SHA-256 for supported files;
- retain full physical paths;
- determine the relevant original folder label;

7. Duplicate rules
SHA-256 is authoritative for binary duplicate detection.
Example:
F:\phd-rag\data\literature\AI\smith2024.pdf
F:\phd-rag\data\literature\Algorithms\smith2024-copy.pdf

If both have the same SHA-256:
unique_documents = 1
duplicate_copies = 1

Preserve both paths:
physical_locations:
- F:\phd-rag\data\literature\AI\smith2024.pdf
- F:\phd-rag\data\literature\Algorithms\smith2024-copy.pdf

Preserve both folder labels:
original_folders:
- AI
- Algorithms

Do not create two logical documents.
Two files with the same filename but different content must not be treated as duplicates.
