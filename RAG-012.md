3. Deterministic validation first
Start with deterministic checks:
cited source exists
source is evidence eligible
source text available
quotation exists verbatim when quoted
numeric values in claim appear in source where applicable
author/year metadata available
DOI normalized
page provenance available when present
bibliography-like chunks rejected

Do not add another LLM unless deterministic checks cannot decide.
4. Semantic support check
For ordinary paraphrased claims, use a lightweight semantic/entailment layer only if needed.
Prefer reusing existing local models/components before introducing a large new dependency.
Return:
SUPPORTED
PARTIALLY_SUPPORTED
UNSUPPORTED
UNCERTAIN

Preserve:
validator_method
confidence
reason
source_ids

Do not silently upgrade UNCERTAIN to SUPPORTED.
5. Multi-source claims
If a sentence cites:
[S1,S4]

validate whether:
S1 alone supports it
S4 alone supports it
or the combination is required

Record support per source and combined support.
This should catch the RAG-011 failure mode where two separate findings were compressed into one sentence.
6. Numeric claims
Numeric claims require stricter handling.
Detect values such as:
percentages
sample sizes
p-values
effect sizes
years
counts
ranges

For these, verify that the number is present in cited evidence or directly derivable.
If not:
UNSUPPORTED

Do not let semantic similarity override a missing number.
7. Quotations
Direct quotes must:
exist in source text
map to the cited S id
preserve page provenance where available

If quote text cannot be found:
validation failure

No fuzzy "close enough" acceptance for direct quotations.
8. OCR and table caution
If:
ocr_involved = true

or:
content_type = table

mark the citation as:
elevated_validation_risk = true

Do not reject automatically, but require stronger checking for numeric/quoted claims.
9. Harvard in-text citations
Convert valid internal markers:
[S1]

to Harvard-style citation:
(Author, Year)

Examples:
(Smith, 2024)
(Smith and Jones, 2024)
(Smith et al., 2024)

Follow the metadata actually available.
Do not invent missing authors or years.
If metadata is incomplete, use a clearly defined fallback and record it.
10. Multiple sources
Example:
[S1,S4,S7]

becomes something like:
(Brown, 2022; Chan, 2024; Smith et al., 2023)

Use deterministic ordering.
Suggested:
alphabetical by first author, then year

11. Harvard reference list
Build one deduplicated reference entry per cited work.
Prefer DOI-based identity first.
Example journal format:
Author, A.A. and Author, B.B. (2024) 'Article title', Journal Title, 12(3), pp. 10-25. doi:...

Use only metadata actually present.
Do not invent:
volume
issue
pages
publisher
DOI
URL

If metadata is incomplete, produce the best safe reference and add:
metadata_warning

12. Reference identity
Deduplicate citations that point to several chunks from the same work.
Identity priority:
DOI
normalized title
document/work identity

Eight chunks from one paper must produce one bibliography entry.
